# Residential Real Estate Pricing Analysis

## 🧠 Project Summary
This project is an end-to-end analysis of residential real estate pricing using Python, SQL (SQLite), and Looker Studio.  
The goal is to identify key factors that influence property prices and to present insights in an interactive dashboard.

---

## 📊 Key Insights
- Larger area significantly drives higher prices  
- More bathrooms and bedrooms increase property value  
- Furnished homes command a premium  
- Amenities like air conditioning and parking positively impact price

---

## 🛠 Tools & Technologies
- **Python** — Data cleaning, modeling, analysis  
- **SQL (SQLite)** — Data storage and analytical queries  
- **Looker Studio** — Interactive dashboard  
- **Git & GitHub** — Version control & project sharing

---

## 🧪 Project Workflow
1. Loaded and cleaned data using Python  
2. Built regression models (Linear & Random Forest)  
3. Stored cleaned data in SQLite  
4. Ran SQL queries for analytical insights  
5. Built interactive dashboard in Looker Studio
